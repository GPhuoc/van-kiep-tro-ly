# Vạn Kiếp Tu Tiên Tool · Trợ Lý

Mod trợ lý cho game Vạn Kiếp Tu Tiên. Tác giả: Minhndt3 · Shgphuoc · Kỹ Sư Claude.

## Cài
1. Bấm nút xanh **Code** → **Download ZIP**, hoặc tải từng file `main.js` + `mod.yaml` vào một thư mục `van_kiep_tro_ly`.
2. Trong game: Cấu hình → Mods → Cài mod → chọn file zip, bật mod rồi tải lại trang.

## Tự cập nhật
Tool tự kiểm tra bản mới ở repo này (Hệ Thống → Cập nhật). Bấm Cập nhật là xong, trang tự tải lại khi an toàn.
`version.json` là thông tin bản mới nhất mà Tool đọc.
